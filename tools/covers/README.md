# 커버 이미지 생성기

글 목록·히어로·글 머리에 쓰는 대표 이미지(1200×675 SVG)를 만들어
`assets/images/covers/` 에 넣습니다.

```bash
node gen.js ../../assets/images/covers
```

## 왜 직접 그리나요

참고할 만한 데이터센터 도표는 웹에 많지만, 대부분 **스톡 사진이거나 기업 자료**라
블로그에 그대로 올릴 수 없습니다. 그래서 **같은 화풍(아이소메트릭 + 라벨)을 코드로
다시 그립니다.** 색은 사이트 팔레트를 쓰고, 부품은 아래 것들을 조합합니다.

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `iso.js` | 아이소메트릭 투영, 상자·판·바닥타일·선 같은 기본 도형 |
| `parts.js` | 랙, 캐비닛, 배터리, 발전기, 변압기, 버스덕트, 냉동기, 노트북, 계층 판, 라벨 |
| `gen.js` | 장면(scene) 정의 + 자동 맞춤 프레임 |

## 좌표 잡는 법

`hx` 는 **화면 가로**, `depth` 는 **화면 세로**, `y` 는 **높이**입니다.
실제 x/z 축은 `iso.js` 가 알아서 바꿉니다.

- `row(hx, depth, step)(i)` — x 축을 따라 i 번째 자리. 화면에서 **오른쪽아래로** 줄지어
  갑니다. 랙 한 줄을 세울 때 씁니다.
- `back(hx, depth, gap)` — z 축으로 한 줄 밀기. 화면에서 **왼쪽아래로** 갑니다.
  랙 두 번째 줄을 놓을 때 씁니다.

## 크기는 자동으로 맞춥니다

`frame()` 이 그려진 좌표를 전부 훑어 장면의 실제 크기를 재고, 캔버스에 꽉 차게
scale·translate 를 계산합니다. **장면을 고칠 때마다 배율을 손으로 맞추지 않아도 됩니다.**

좌우 여백(`marginX`)은 일부러 넉넉히 둡니다. 히어로 자리는 16:10 틀에 16:9 그림을
`object-fit: cover` 로 채워서 **좌우가 6% 쯤 잘리기 때문**입니다. 라벨을 가장자리에
바짝 붙이면 잘립니다.

## 새 장면 추가하기

`gen.js` 의 `scenes` 에 항목을 하나 더 넣으면 파일 이름이 그대로 만들어집니다.

```js
'my-post': () => {
  const o = [];
  o.push(floor(8, 5, { hx0: -112, depth0: -48, step: 30 }));
  const R = row(16, -30, 30);
  for (let i = 0; i < 4; i++) o.push(T.rack(...R(i), { slots: 9 }));
  o.push(T.label(...R(0), 56, 'RACK', { dy: -30, size: 9 }));
  return frame('mypost', `<stop offset="0%" stop-color="#3B32B0"/><stop offset="100%" stop-color="#38BDF8"/>`, o.join('\n'));
},
```

라벨은 **영어 대문자로 4~6개까지**. `size: 9` 가 기본이고, 겹칠 것 같으면 `dy` 를
번갈아 (`-28`, `-50`) 줘서 위아래로 엇갈리게 놓습니다.
